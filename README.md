
# ✨ GlowBar - Beauty & Skincare Website

GlowBar is a modern and elegant beauty website designed to provide a premium online experience with beautiful animations, dynamic service pages, and a seamless online booking system.

## 🌸 Features

- ✨ Beautiful and smooth animations
- 🏠 Home page with an elegant and modern design
- 👩‍💼 About page to introduce the brand
- 💅 Services page with multiple beauty categories
- 🔄 Dynamic service pages for individual services and categories
- 📅 Online appointment booking system
- 📩 Contact page for customer inquiries
- 📱 Fully responsive design for mobile, tablet, and desktop
- 🎨 Modern UI/UX with smooth navigation
- ⚡ Fast and user-friendly experience

## 📄 Website Pages

- Home
- About
- Services
- Dynamic Service Categories
- Contact
- Online Booking

## 🛠️ Technologies Used

- Next.js
- React.js
- TypeScript
- Tailwind CSS
- MongoDB
- REST APIs
- Animation Libraries

## 📱 Responsive Design

GlowBar is fully responsive and optimized for different screen sizes, providing a smooth and consistent experience across desktop, tablet, and mobile devices.

## 🎯 Project Purpose

The main goal of GlowBar is to create a beautiful digital platform where customers can explore beauty services, discover different categories, and conveniently book appointments online.

## 💖 Highlights

- Elegant beauty-focused design
- Engaging animations and transitions
- Dynamic service content
- Convenient online booking experience
- Clean and responsive layouts
